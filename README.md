# Projeto Elo Alimentar 

Plataforma web desenvolvida como MVP (Produto Mínimo Viável) para a disciplina de **Desenvolvimento de Sistemas Web**, com foco no combate ao desperdício de alimentos e no apoio a organizações do terceiro setor.

## Sobre o Projeto
O **Elo Alimentar** resolve o déficit logístico entre o alto índice de desperdício de alimentos no varejo e a demanda constante de ONGs que combatem a insegurança alimentar. A plataforma funciona como um mural de necessidades em tempo real, conectando doadores a instituições beneficentes de forma ágil.

### ODS Atendidas (Objetivos de Desenvolvimento Sustentável)
* **ODS 2:** Fome Zero e Agricultura Sustentável.
* **ODS 10:** Redução das Desigualdades.
* **ODS 12:** Consumo e Produção Responsáveis.
* **ODS 17:** Parcerias e Meios de Implementação.

---

## Funcionalidades Principais
1. **Autenticação e Perfis:** Cadastro e login diferenciados (Doador e ONG) com persistência local.
2. **Gestão de Lotes:** Painel para o varejo cadastrar, editar e gerenciar alimentos próximos ao vencimento.
3. **Vitrine de Doações:** Mural dinâmico para as ONGs visualizarem e filtrarem lotes disponíveis.
4. **Reserva e Agendamento:** Sistema de solicitação e alteração de status de retirada.
5. **Acompanhamento de Status:** Painel para monitorar o ciclo do lote (*Disponível → Reservado → Concluído*).

---

## Tecnologias Utilizadas
* **HTML5 / CSS3 / JavaScript (Vanilla)**
* **LocalStorage** (para persistência de dados em ambiente front-end puro, sem banco de dados externo)
